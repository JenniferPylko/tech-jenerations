# ∫Tech Jenerations

This [modpack](modlist.md) is based around detailed and balanced progression, with inspiration from actual geology, chemistry, physics, and other sciences. Right now the pack is in early alpha, so please submit issues for any problems, especially broken progression and duplicate items.

You can read the [in-game guide](kubejs/assets/kubejs/guides/kubejs/guide/index.md) (sans guideme features) right in github.
